# シンプルまるごとZIP v1.2.0 — X新旧メディアUI・Bluesky対応

Xの新旧メディア画面に対応し、Blueskyの公開APIによる画像・動画の収集とZIP保存を追加したバージョンです。既存の収集状態・分割ZIPのチェックポイント・差分収集の機能は維持しています。

## 今回の主な変更

- **X新UI**：動画ページ（`/media`）と画像ページ（`/media?filter=photo`）を自動モードで順に巡回し、投稿ID＋メディア番号で重複を除いて統合。動画0件でも画像へ移動します。旧UIを使用中なら従来の混在表示を1回だけ収集します。
- **旧UI化オプション**：設定画面にプロフィールタブを従来表示へ戻す設定を追加。初期値は新UI収集ON／旧UI化OFF。Control Panel for Twitter等による旧UI化とも併用可能です。
- **Bluesky**：公開プロフィールの投稿に添付された画像・動画をAPI収集。投稿者のPDSのBlobを優先し、PDSへのホスト権限を必要時に確認します。アカウント認証やAPIキーは不要です。
- **保存と表示**：メディア0件の種類だけを選択した場合はZIP保存を開始せず、画面内で案内。保存中のエラーが緑のボタンに重ならないよう調整。
- **429待機と復帰**：待機中の表示を「自動再開予定」から「待機解除予定」へ修正。対象タブが利用可能なら再開を試み、Xのエラー画面等で再開が拒否された場合は、収集中と誤表示せず青ボタンからの手動再開に切り替えます。

## 実機で確認済みの内容（KINAによるv1.1.1新UIテスト版の検証）

- Xの同一アカウントで、新旧UIの取得結果が**画像147／動画27**で一致。新UIから動画のみ／画像のみ／両方のZIP作成に成功。
- X新UIの動画0件・画像610件のアカウントで画像ページへの自動切り替えと、両ページでの停止・別タブ移動・再開、既存280件からの継続を確認。
- Xの429後、待機解除予定時刻に青ボタンが操作可能になり、手動で新規分0件を確認。すべての環境で自動再開できることを実機確認したものではありません。
- Blueskyは別PCで**画像6,807／動画242、計7,049件の収集**を確認。以前にBlueskyで300件×2 ZIPの保存・途中ZIPからの累積600件復元を確認。7,049件すべてのZIP保存・再生を確認したという意味ではありません。

今回のv1.2.0で変更した文言・429再開失敗時の安全停止についてはオフライン回帰テストを追加しました。**このパッケージ自体の最終Chrome実機確認と公開判断は別途必要です。**

## 更新・初期設定

更新前に設定画面から全体JSONを保存し、既存の拡張を削除せず更新してください。初期の収集方法は従来どおり**手動**で、全件ZIP保存には「無制限」を選択します。X新UIの自動巡回は自動モードを選んだときだけ実行します。

Xの旧UI化を有効化した場合はXページを再読み込みしてください。429に遭遇した場合は再試行を繰り返さず待機してください。SNSの利用規則やメディアの権利については利用者自身で確認してください。
