# シンプルまるごとZIP v1.1.1 — Bluesky対応

X（旧Twitter）に加え、Blueskyの公開プロフィールから画像・動画をAPI経由で収集できます。ログイン・APIキーは不要で、投稿者のPDSにあるBlobを優先して取得し、300 MBまたは300ファイルで自動分割します。

## 今回の修正

- 保存対象0件ではZIP保存を開始せず、チェック欄に案内を表示。
- エラー通知をステータス欄に収め、ZIPボタンへの重なりを修正。
- 旧β版で0件選択した際の持続エラーを修復。既存の保存済みチェックポイントは維持。
- X版の収集・ZIP分割・復元と、認証情報をバックアップに含めない方針を継続。
- **X新旧UI対応の検証中**：デフォルトで新UIの動画ページと画像ページを順に収集。詳細設定から旧プロフィール表示への復元も選択可能（初期OFF）。2ページ間の一時停止／再開と、別拡張による旧UI化を考慮したオフラインテストを追加。

## 検証状況

KINAによる実機検証：Blueskyで7,035件収集、001.zipと002.zipに300件ずつ保存、途中再開・002.zip単独から600件の状態復元を確認。オフライン回帰テストは `tests/` を参照。

**公開前に確認が必要**：v1.1.1のChrome実機で0件UIを確認し、取得動画の再生・Blueskyの差分収集・X/Bluesky混合全体バックアップの復元を確認。一般公開前には最新版のチェックリストを完了してください。

## インストール

ZIPを解凍し、Chromeの `chrome://extensions/` でデベロッパーモードをONにして、`simple-marugoto-zip` フォルダを「パッケージ化されていない拡張機能を読み込む」から指定してください。更新前に、設定画面から全体JSONをバックアップしてください。
