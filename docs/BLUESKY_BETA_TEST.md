- [x] **プロフィール認識（本人アカウント）**: `https://bsky.app/profile/<handle>` を表示して拡張を開き、対象が正しく表示される。X版と混在しない。

- [ ] **動画**: 投稿者のPDSからBlobを取得できる動画でファイル再生を確認。PDSが拒否した場合は失敗件数を確認。HLSをMP4と偽って保存しない。

## 既知の制限

- 一部のChrome実機ケースのみ検証済み。公開投稿のみ。Bluesky Web画面のメディア／ビデオタブをスクロールする仕組みではありません。
- APIの表示形式、データ取得範囲、PDSごとの直接Blobアクセスに依存します。投稿前の完全オリジナルファイルを復元できる保証はありません。
- CIDを取得できない画像・動画やPDSが返さない動画は保存に失敗する場合があります。リンクカードは対象外。
- APIが429を返したら収集を停止し、少なくとも15分間待機してからユーザーが明示的に再開します。制限回避のためにアカウントやPDSを切り替えません。
- `did:web` の独立ドメインや、公式Blueskyアカウント以外のPDSで追加のブラウザ権限が必要になることがあります。一般的な`did:plc`から先にテストしてください。
- 動作確認用の**5ファイル**が初期値です。全件保存時は**無制限**を選択してください。
