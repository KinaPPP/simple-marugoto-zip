# v1.0.0 Release Notes（下書き・公開しない）

> 公開前の最終実機テストとXの利用規則に照らした公開方式の確認が終わるまでは、`v1.0.0` として発行しないこと。

**シンプルまるごとZIP** 初回安定版。Xのメディアを種類別に収集・ZIP保存し、途中再開、差分チェック、バックアップ状態の移行に対応。

## 主な機能

- 画像・動画（アニメーションGIF含む）の収集、保存対象の選択、種類別連番ZIP
- 手動収集と、新規分だけの差分収集
- 初期設定は手動。必要に応じて自動収集を選択可能
- ZIP自動分割は300 MBまたは300ファイル（いずれか先に到達した条件）
- ZIP作成中の進捗・429待機・完了通知
- 分割ZIPへのアカウント状態JSON同梱、全体JSONのインポート／エクスポート
- 保存先の連続利用、設定画面の簡略化、本拡張データの全体初期化

## インストール

配布ZIPを展開し、Chrome `chrome://extensions/` から「パッケージ化されていない拡張機能を読み込む」で `simple-marugoto-zip` フォルダを指定してください。

## 制限と注意

対応SNSは現時点でXのみ。Xの内部Web仕様が変わると取得できない場合があります。本拡張は非公式です。手動収集を選んでもXの利用許可を保証するものではなく、自動収集もX側の自動化規則によって制限される可能性があります。利用者は利用規則を確認し、アクセス制限が発生した場合は使用を中断してください。バックアップJSONに認証情報は含みませんが、アカウント名・投稿ID・メディアURL等は含まれます。

設定画面からの疑似429ボタンと10ファイルZIP分割は開発中の診断機能として削除済み。429のオフライン回帰テストは開発用の `tests/` に保持しています。
