# シンプルまるごとZIP v1.3.0 — Threads対応・設定画面再設計・復元強化

v1.3.0では、X・Blueskyに加えてThreads APIによるメディア収集へ対応しました。あわせて設定画面、API収集の復旧、ZIP／JSON復元、差分バックアップを整理しています。

## 主な変更

- **Threads対応**：本人投稿の画像・動画・カルーセルをThreads Graph APIで収集。利用者自身が取得した長期アクセストークンを使い、専用中継サーバーは使用しません。公開プロフィールの取得範囲はMetaアプリの権限・アクセスレベル・審査状態に依存します。
- **Threadsトークン管理**：長期トークンの保存、自動更新ON/OFF、手動更新、ローカル保存トークンの削除に対応。トークンはChromeの `chrome.storage.local` に保存し、ZIP／JSONバックアップへは出力しません。
- **設定画面を3タブ化**：「対応サービス」「バックアップ・復元」「保存データ」に整理。X／Bluesky／Threads固有の設定と、低頻度の管理操作を分離しました。
- **API収集の復旧**：Threads／Blueskyはページ単位で取得結果と次カーソルを同時保存し、MV3 Service Worker再起動後も最後に確定した位置から復旧。再取得時はメディアキーで重複を除外します。
- **復元ロックを細分化**：別SNS・別アカウントの処理中でも安全な復元は可能。処理中の当該アカウント上書きと全体置換だけを拒否します。
- **差分バックアップをスナップショット化**：差分ZIPに前回までの累計情報を保持。最新の差分ZIP 1個だけでも「今回」と「累計」を復元でき、古い全件ZIPはその時点のチェックポイントとして利用できます。
- **完了判定を改善**：取得失敗が記録されていても、全項目の保存処理が終わっていればZIP完了として扱い、失敗履歴を保持したまま次の差分チェックへ進めます。

## 実機で確認済み

- Threads本人アカウントで **2,825件（画像2,752／動画73）** を全件収集。途中停止後、約30分空けて続きから再開。
- 10分割ZIPを最後まで保存。004.zipから状態を復元して005〜010.zipを継続し、最終010.zip単独からも即座に完了状態を復元。
- 新しいMeta App ID / App Secretから「Threadsトークン 取トーくん」で長期トークンを取得し、まるごとZIPへ新規登録して収集開始。手動のトークン更新も正常動作。
- 010.zip復元後の新規チェックで追加画像3件を検出し、新しい日時の001.zipとして保存。差分001.zip単独から **今回3件／累計2,828件** を復元。
- Threads収集中に別のXアカウントを収集・ZIP保存できることを確認。

## 更新時の注意

更新前に設定画面から全体JSONをバックアップしてください。既存の拡張を削除せず、同じ展開先をv1.3.0へ更新してChromeの拡張管理画面から再読み込みすると、通常は既存状態を維持できます。

Threadsを利用する場合は、利用者自身のMetaアプリと長期アクセストークンが必要です。長期トークン取得には [Threadsトークン 取トーくん](https://kinappp.github.io/threads-token-tool/) も利用できます。保存トークンは共有PCでの取り扱いに注意してください。

本拡張はX・Bluesky・Threadsの非公式ツールです。各SNSの規則、API制限、保存対象メディアの権利を確認して利用してください。
