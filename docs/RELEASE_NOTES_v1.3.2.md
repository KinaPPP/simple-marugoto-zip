# シンプルまるごとZIP v1.3.2 — 保存先フォルダ変更

v1.3.1の収集・ZIP・復元仕様を維持したまま、保存先フォルダだけを後から変更できる小改善です。

## 変更内容

- ポップアップの「保存先: フォルダ名」の横に `[変更]` を表示します。
- `[変更]` から新しいフォルダを選ぶと、収集件数・ZIP進捗・差分状態を消さずに保存先だけ切り替わります。
- ZIP保存中は変更できません。ZIP停止中・保存完了後・アクセス制限等の待機中は変更できます。
- 分割ZIPの途中で変更した場合は、すでに確定したZIPは元の場所に残り、次に作るZIPから新しい場所へ保存します。
- フォルダ選択をキャンセルした場合は変更しません。状態更新に失敗した場合も以前の保存先ハンドルへ戻します。
- 差分状態から前回状態へ戻しても、変更した保存先を維持します。

## 変更していないもの

- 収集済みメディア、ZIP番号、保存済みキー、差分境界などの進捗。
- X / Bluesky / Threads の収集仕様。
- バックアップへ認証情報を含めない方針。

## 確認項目

1. ZIP保存完了後に `[変更]` を押し、新しいフォルダを選択する。
2. 次のZIPが新しいフォルダへ保存される。
3. 変更画面をキャンセルした場合は従来フォルダが維持される。
4. 分割ZIPを停止した状態で保存先を変更し、再開後の次ZIPだけが新しいフォルダへ保存される。
