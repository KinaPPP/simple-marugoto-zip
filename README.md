# シンプルまるごとZIP / simple-marugoto-zip

画像・動画を収集し、`images/` と `videos/` に整理して分割ZIPへ保存するChrome拡張機能です。作者 **KINA**、ライセンス **MIT**。

- **v1.0.0 正式版：X（旧Twitter）対応**。手動スクロール収集が初期設定、自動収集も選択可能です。
- **v1.1.1：Bluesky対応（正式版の公開前確認中）**。公開APIから収集し、画面のスクロールやAPIキーは不要。X版の収集・保存も引き続き利用できます。
- Threads対応、Firefox版は将来の検討事項です。

## できること

- 画像・動画、または片方だけを選んでZIP保存。自動分割は **300 MBまたは300ファイル** の早い方。手動で500 MB／1 GB／500ファイルも選択できます。
- 保存の中断・再開、完了まで保持する緑の`✓`、新しく追加されたメディアだけの差分チェック。
- 分割ZIPそれぞれに `backup-state.json` を同梱。設定タブから全アカウントの状態をJSONにエクスポートし、ZIP／JSONをドロップして復元できます。
- 初期設定の**5ファイル（動作確認）**は、1回にZIPへ保存するファイル数の上限です。すべて保存するときは **無制限** を選択してください。

## インストール

ZIPを展開し、Chromeの `chrome://extensions/` →「デベロッパーモード」ON →「パッケージ化されていない拡張機能を読み込む」→ 展開した `simple-marugoto-zip` フォルダを指定してください。

**更新前に全体JSONを保存してください。** 展開したフォルダを更新して「再読み込み」すれば、同じ拡張のローカル保存情報は通常維持されます。異なるフォルダを別の拡張として読み込んだ場合は、各拡張で保存情報が分かれます。

## Bluesky（v1.1.1）

1. `https://bsky.app/profile/アカウント名` を開き、拡張アイコンをクリックします。
2. 「メディアを収集」を押します。投稿者のPDSへのアクセス許可が必要な場合は、**そのPDSだけ**許可してください。アカウント認証やAPIキーは不要です。
3. 公開APIから画像・動画付き投稿を取得します。画面をスクロールする必要はありません。途中停止・再開も可能です。
4. 収集が終わったら画像／動画を選び、ZIP保存します。**すべて保存するなら「無制限」へ変更**してください。前回のZIP保存後に「新規分をチェック」も利用できます。

**保存画質：** 投稿に記録されたCIDから、投稿者のPDSに存在する元のBlobを最優先で取得します。画像のBlobを取得できない場合は表示用の大きな画像へフォールバックします。動画のBlobを取得できない場合は**勝手に別の動画へ変換せず取得失敗として記録**します。Blueskyへの投稿時点で圧縮・再変換された画像／動画は、投稿前のファイルには戻せません。リンクカードのサムネイル、他人のリポスト・引用元メディアは収集対象外です。

Blueskyの利用者のPDSによっては、ブラウザからBlobを直接取得できない場合があります。公開前の最終確認として、動画の再生・差分取得・異なるPDSの環境差を確認してください。手順と既知の制限は [Bluesky テスト表](docs/BLUESKY_BETA_TEST.md) を参照してください。

## X（v1.0.0から継続）

Xのプロフィール／`/media` ページで拡張を開き、「メディアを収集」を押します。初期設定の手動モードではX画面を自分でスクロールし、必要な範囲を読み込んで「収集を完了」。必要なら自動モードも選択できます。詳しい従来仕様は [X版v1.0.0の詳細](docs/X_V1_REFERENCE.md) を参照してください。

本拡張は非公式ツールです。利用先SNSの規則・アクセス制限を確認してください。制限が発生した場合は使用を中断してください。注意書きはSNSからの利用許可を意味しません。

## バックアップと個人情報

`backup-state.json`／全体JSONには対象アカウント、投稿ID、取得URL、保存済み／未保存の境界などが入ります。**Cookie、パスワード、APIキー、アクセストークン、保存先フォルダの権限は出力しません。** ZIP／JSONの外部共有前には内容を確認してください。詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## Xの新旧メディアUIへの対応（v1.1.1 検証版）

設定画面の「Xの新旧メディア表示」で、新UIの動画／画像ページを順番に収集（初期ON）するか、Xのプロフィール表示を旧UIに戻す（初期OFF）かを選べます。初期設定ではXの表示を変更しません。自動収集では新UIの動画ページと画像ページを1つのアカウント情報に統合します。旧UIを別の拡張機能で復元している場合も従来の収集経路を利用します。

**新UIの実機取得は検証待ちです。** 操作方法と確認条件は `docs/X_NEW_UI_TEST.md` を参照してください。
